| D10 | EDA | Negative weights | Flip sign (absolute value) | 292 train / 145 valid; flipped values match positives in range (5,000–47,500), percentiles and per-equipment medians; spread proportionally across equipment → sign errors |
| D11 | EDA | Missing weight | Fill with one overall training median; no flag | 300 / 165 rows; medians nearly identical across equipment; missing rows priced like others (median factor 1.001 vs 1.000) → random |
| D12 | EDA | Missing market_index | Same-date mean from the same file; fallback previous date's mean, then next date's (safety nets, never triggered); no flag | Varies per load but within ±0.03 inside a date; no fully-missing dates; missingness random (factor 0.994 vs 1.000) |
| D13 | EDA | Extreme rates | Exclude rows with factor <0.5 or >2 vs median rpm by equipment × distance band (edges [0, 250, 500, 1000, 2000, 4000] mi, right-inclusive) from TRAINING only; table learned per training fold; score holdouts on all rows; test vs keeping in Phase 3/4 | Full-file rule flags 677 rows (1.41%; 337 low / 340 high) priced 2–6× off similar loads; uniform across months, equipment, distance; clear gap from normal (98% within ±15%) → consistent with label errors, not spikes. Per-fold counts will differ slightly |
| D14 | EDA | Categories | No clean-up rule; safety check rejects unknown equipment | 3 equipment values, no case/space variants; December text exact |
| D15 | EDA | Distance, coordinates, cities | Keep distance unchanged; use coordinates (relative positions), not city names; December coordinates from training lookup | 70-mile floor + short trips explain high ratios; prices consistent; coordinates synthetic but consistent; 8 cities only in validation (1,447 rows, 12.1%); Laredo outside training map (195 rows) |
| D16 | EDA | quote_signal | Drop; confirm with Jan–Jul → Aug test in Phase 4; no month/date-counter features | ≈ rpm in 5 months, mirrored in 4, noise in Aug; validation spread (0.22) matches Aug (0.223) → unstable, leakage-like |
| D17 | EDA | market_index for December | Validation's daily mean for each December date | December file lacks the column; validation has real values for those dates; a feature, not a label → no leakage |
| D18 | EDA | Cleaning function design | fit_cleaning(train) → saved dict (weight median, city coordinates); clean(df, learned) applies rules to a copy of any file | Learned values come from training rows only (no leakage); one shared function guarantees identical cleaning in train and predict |
| D19 | EDA | Notebook outputs in Git | Committed with outputs | Reviewers see the EDA evidence without rerunning; only small excerpts, not the data files (D4) |
| D20 | Split | Main holdout | Train Jan–Aug → test Sep–Oct (38,477 / 9,523 rows); checkpoints only (baseline, chosen model, final model) | Same 2-month horizon and low-market regime as Nov–Dec validation; B (Jan–Jul → Aug–Oct) too pessimistic; C (→ Oct) only 1-month horizon |
| D21 | Split | Decision fold | Train Jan–Jul → test Aug (33,718 / 4,759) for experiments, incl. D16 quote_signal test; Phase 5 walk-forward folds used for choosing end by Aug | Protects the main holdout from tuning; Aug sits inside main's training side, never touches Sep–Oct |
| D22 | Split | Metrics | All in dollars: MAE primary, MAPE second, RMSE + bias (pred − true) reported; adopt a change only if MAE improves without clearly worse MAPE | Spotter's metric unknown; MAE in deliverable units and less distorted by label errors than RMSE; hand-written, cross-checked vs sklearn |
| D23 | Split | Per-fold pipeline | run_split: split raw → fit_cleaning(train) → clean both → price table from train, drop flagged train rows → fit → predict $ → check (n, finite, >0) → score all holdout rows. Models: fit(train) / predict(df) → dollars; fresh model per split | Same pipeline and metrics for every model and split; leakage evidence recorded (cleaning row count) |
| D24 | Split | Baselines | B0 global median rate; B1 median rpm by equipment × band × distance. Bar: B1 main MAE $140.53 / MAPE 6.40% (all rows); decision $136.60 / 6.39% | B1 cuts B0's MAE by ~88%; equipment + distance explain most of price |
| D25 | Split | Reporting | Headline = all holdout rows; clean-only row clearly labelled; breakdowns by equipment, band, month; holdout label-error flags use the training table, reporting only. Saved to outputs/phase3_baseline_scores.csv | Label errors = 1.5% of holdout rows but 96.7% of B1's squared error (clean RMSE 116 vs 639) |
| D26 | Split | Random-split comparison | Same pool, same test size (9,523), 3 seeds, comparison only. Result for B1 (clean): random MAE $101.03–101.16 vs time $85.01. Repeat with Phase 4 model | Random split was harsher for a time-blind baseline: monthly price levels swing (bias +$134 Jan, −$112 Jun); seed spread $0.13 ≪ gap $16 |
| D27 | Split | Target scale (provisional) | log(rpm); compare with log(rate) in Phase 4; dollars = exp(pred) × distance; check dollar bias for a smearing correction | log(rpm) skew −0.04 vs log(rate) −0.49 and bimodal; log(rate) = log(rpm) + log(distance) |
| D28 | Split | Label errors in baseline training | Excluded (D13); kept-vs-excluded identical for baselines (B1 $136.60 vs $136.61); real test in Phase 4 | Medians ignore a 1.4% minority; per-fold flags matched full-file flags exactly (465, 533) |
| D29 | Split | Unseen-cities check | Deferred to Phase 4/5 with the model | B0/B1 use no location, so holding out cities would show nothing |
